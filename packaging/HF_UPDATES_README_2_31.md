# Runtime updates for game 2.31 (old)

**You do not need these any more.** Since 0.3.4 the update for game 2.31 on [Nexus Mods](https://www.nexusmods.com/cyberpunk2077/mods/35436?tab=files) carries all of the mod's code, and it runs on any Runtime of version 0.3.3 or newer. If your install is older than 0.3.3, or Settings > Help says the Runtime is too old, install the full install for game 2.31 from [Nexus Mods](https://www.nexusmods.com/cyberpunk2077/mods/35436?tab=files) over it: one zip, no steps. Your settings and memories are kept.

These are the small zips that brought a Runtime up to date step by step, up to 0.3.3, for the older game version **2.31**. Game 2.5 is the default: if your game is 2.5, see the folder above, [`updates/`](https://huggingface.co/alystria-ai/ai-npc-cyberpunk-mod-packs/tree/main/updates).

If you still want to use them: **apply the update zips from this folder one by one, starting from your version.** Extract each one into your Cyberpunk 2077 folder over your existing Runtime, in the place of the full Runtime, then the next one, until you reach the newest. If Windows asks about files that already exist, choose **Replace**: that is always safe. You do not delete anything yourself: files a version no longer needs are removed by the mod the next time the game starts. The update zip for game 2.31 (`game-2.31/AI-Companions-LLM-Update.zip`) and any optional packs are downloaded as usual.

With Vortex, drop each update zip onto the Mods page one by one, oldest first, together with the new update zip. When Vortex asks, choose "Replace the existing mod" (it may first ask to replace the file, say yes), then click Deploy. With Mod Organizer 2, extract each one into the Runtime mod's folder.

Every step is kept here. If you are not sure which version you have, use the full install instead. It works for new installs and for any update.
