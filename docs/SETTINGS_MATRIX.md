# Settings matrix and audit, 2026-10-20

The audit write-up of branch `audit/settings-matrix` (from main 2c19ac29). It was meant for `deliverables/settings-audit-2026-10-20.md`; the file tool there was refused, so it lives here. Committed, NOT merged, NOT pushed, NOT installed, game not launched, no live cloud or Convai turn. `mod/` needs a CET reload (all committed Lua and the 15 locales), `bridge/` a bridge restart.

**Update 2026-10-20 (branch `feat/settings-decisions`):** the owner decided D1 to D8 (section 3) and removed five settings; this file now describes the code after those changes. Rows and findings that changed say so. Old saved keys of every removed setting are ignored and dropped from the file once.

Scope: every player setting on Settings and Relationships, the credentials, the hidden keys of `runtime/settings.json`, and the install states that feed them. Method: read both rule sets (Lua `mod/manager.lua`, `mod/manager-ui.lua`; the bridge's settings poll in `bridge/convai-bridge.mjs` and the modules it feeds), list every pair of settings where one reads, forces or refuses the other, and walk each pair plus the triple provider × voice × Mature through the page, the load path (an old or hand-edited file) and the bridge. Left to other branches: the Mature pin and the Local AI model row (`fix/mature-off-models`, `bridge/local-model-choice.mjs`) and the free-VRAM fit (`bridge/local-llm-server.mjs`).

Counts (before the 2026-10-20 changes): **36 page settings** (35 keys, the 5 relationship rows under one key); after them **27 page rows** (**26** since 2026-10-28, when `followUpInterest` went): `johnnyHologram`, `vTalks`, `autoConnectNearby`, `expressiveEmotions`, `gameDialogueContext`, `holocallLiveImage` and `bodyGestures` are gone (`naturalSpeech` and `followUpInterest` stayed then, and `followUpInterest` went on 2026-10-28), Johnny in your head and Johnny speaks up are one list row, V's voice for typed lines and V's voice engine are one list row (each of those two rows writes both of its file keys), and the read-only Johnny standing line is gone, **3 credentials** (Mistral key, Convai key, Custom endpoint URL/key/model), **4 rows per add-on with speakers** plus its own items, **9 hidden file keys**, **32 interacting pairs** (the 32nd, V's OmniVoice engine, was added 2026-10-21).
