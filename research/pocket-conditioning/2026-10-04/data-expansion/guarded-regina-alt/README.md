# Guarded Regina and direct-record Alt collection

This code-only addition preserves the exact independently reviewed source implementation used for the expanded voice dataset. Runtime paths and hashes are recorded in `source-manifest.json`. Raw scenes, audio, model weights and large candidate/proof receipts remain in the ignored runtime workspace.

## Regina

The old registered MAIN mirror predicate assumed every scene assigned bit1 to the `holo` execution tag. Actual Regina scenes assigned `holo=2` and `arms_crossed=1`. The isolated reader resolves the unique scene-declared nonzero single bit and requires exact equality. It retains the original Full/exact-one/Holocall, actor-ID, native-voice, acquisition, English and MAIN gates. Four actual non-holo observations remained excluded.

Native source routing also distinguishes the world actor `#reggie` from `#reggie_holo`. The reviewed guard derives the latter from the actual same-line native mirror relationship; it does not infer identity from a matching name or voice alone. Each target retains its own exact acquisition, voice, actor pointer, line, event and language checks. Every required anchor/bridge/target resource is authenticated under the existing CPU lease before audio access.

`decode_regina_batch.py` pins that guard and the isolated reader/bridge. A source in the new holo world cannot omit the guard to fall back to a plain alias. Guard failures never reach the completed-row path. Successful before-audio authority receipts are immutable, content-addressed sidecars referenced by each collection row's `canonicalHoloAuthority`. They explicitly claim no direct TweakDB record edge. The original per-line production-format receipt and WEM/WAV remain unchanged.

Actual result: all201 planned Regina recordings completed without source/decode errors. Usable TRAIN admission and aligned duration belong to the separate qualification/corpus lanes. No cache optimization speedup is claimed here.

## Alt

The production roster has79 profiles and does not contain the research-only Alt entry used by the voice corpus. `decode_alt_research_batch.py` retains the original production-roster check, then appends only the exact reviewed `Character.Alt` definition under its pinned supplemental proposal. It requires the actual speaking actor in every candidate to expose a direct canonical record; no alias or voice-only shortcut is permitted. The runtime roster is not modified.

Actual result: seven direct-record Alt originals completed, totaling21.8951875 recording seconds, with no source/decode errors. Their raw receipts include `provenance.researchSupplement`. Cyberspace/other-world sources without a proved identity chain remain separate and held.

## Reproduction and provenance

The copied files preserve runtime-relative imports. Restore each file to its recorded runtime path before execution; the snapshot directory itself is not an executable deployment. The unchanged Cast and Extract source imports are identified by hash in the manifest. The full current candidate manifests are indexed in runtime `collection/manifest-index-v3.json`; prior index versions and frozen inputs are preserved.

Native game captions are the primary transcript; local STT is fallback when needed. Source/identity/variant, original hashes, role boundaries, alignment and codec checks remain required. Dataset floor coverage is measured from the full actually qualified pool by final corpus assembly, not from old capped pilot counts or unqualified raw recording duration.
